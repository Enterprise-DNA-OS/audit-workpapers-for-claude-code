# Why there is no front end

This workspace handles internal evidence chasing, preparation, review points and assembly records. The agent runs the CLI, reads its result and explains what needs attention. Static dashboards and printable documents provide the view.

It has no live client upload portal, browser editing, mobile evidence capture, offline phone sync, document co-authoring or verified electronic signatures. Evidence remains in the firm's protected document store. A reference is stored here. Teams that need those facilities must retain their existing arrangements until replacement connections and access controls are built and accepted.

AuditFile contains broader functionality, including trial balance tooling and licensed audit programs. This project does not recreate that material or claim functional parity. Its scope is the coordination record. The firm decides which parts of its current process can move, and what stays in specialist software.

Enterprise DNA can build a browser view, document connection or a different stack around the firm's requirements. No audit procedure or opinion is delegated to this software.
