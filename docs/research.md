# Target selection, 18 November 2026

AuditFile was selected for audit-workpaper-coordination, a new family in the rebuild registry. Existing internal-audit, audit-data-analysis and accounts-production builds serve different recurring jobs. This build coordinates preparation, review notes, evidence requests and file assembly; it does not perform statutory audit work or carry the firm's compliance obligation.

## Annual bill and scores

US$29,880 annually is a ten-user scenario: 249 x 10 x 12 at AuditFile Pro Plus annual-agreement pricing. It is not a customer invoice, an NZ/AU usage claim or an all-in migration estimate. It is internal selection evidence and is not quoted on the public page as a vendor package price.

## Vendor sources reopened this run

The FAQ confirms data can be exported but gives no fixed column contract. Prices are from the US vendor site and recorded as USD.
