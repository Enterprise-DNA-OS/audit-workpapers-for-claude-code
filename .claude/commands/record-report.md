# record-report

Record dates from an already issued report and the firm's retention policy. Never issue an opinion or assume these example dates apply.

```bash
npm run audit -- record-report HBR26 --report-date=2026-11-18 --assembly-due=2027-01-17 --retention-until=2034-11-18 --standard="Firm confirmed applicable standard" --actor="Operator"
```

Read the full engagement with history first when changing a record. Names and partial ids work, and ambiguity lists candidates. Stop on errors. Report the resulting record and any unresolved work. Never infer an audit opinion, send a message, or sign for someone without their recorded instruction.
